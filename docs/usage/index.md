# Usage

EarsUp has one job: read a part of a page to you. Everything else helps you start, follow, and control that reading.

## The short version

1. Open a page with headings.
2. Press the blue <span class="twemoji">:material-play-circle:</span> button next to a heading.
3. EarsUp reads that heading and everything under it. The button turns red and becomes stop.
4. Press **Space** to pause, **Esc** to stop, or use the floating player at the bottom.
