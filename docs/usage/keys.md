# Keys & shortcuts

## On the page

These work while EarsUp is reading, on the page you are listening to.

| Key | Action |
|-----|--------|
| ++space++ | Pause or resume |
| ++esc++ | Stop reading and close the player |

**Space** never fires while you are typing in a text box. When EarsUp is not reading, Space scrolls the page as usual.

## Stopped by mistake?

When **Esc** stops reading, a small message appears with a **Take me to settings** button. If Esc keeps stopping EarsUp when you meant to close something else, change the stop key.

![Snackbar after pressing Esc](../media/snackbar.png){ .shot }

Go to **General → Shortcuts**:

| Setting | Options | Default |
|---------|---------|---------|
| Stop key | Esc, Shift + Esc, Off | Esc |
| Pause key | Space, Off | Space |

## From anywhere

Chrome can also run EarsUp shortcuts when the page does not have focus, for example while you are in the address bar.

| Shortcut | Action |
|----------|--------|
| ++alt+shift+p++ | Pause or resume |
| ++alt+shift+s++ | Stop reading |

To change these, open `chrome://extensions/shortcuts`, or click **Change shortcuts** in **General → Shortcuts**. Chrome manages these keys, so another extension may already use them.
