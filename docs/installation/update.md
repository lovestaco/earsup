# Update

1. Download the new `earsup-vX.Y.Z.zip` from the [releases page](https://github.com/lovestaco/earsup/releases).
2. Extract it **over the same folder** you loaded before, and replace the files.
3. Open `chrome://extensions` and click the **reload** arrow on the EarsUp card.
4. Refresh the tabs you want to use it on. Tabs that were open before the update still run the old version until you refresh them.

Your settings, Gemini key, and history stay. They are stored by Chrome, not in the folder.

To see which version you have, open the settings panel and go to **About**, or look at the EarsUp card in `chrome://extensions`.

!!! note "Loaded a different folder?"
    If you extract the new version to a new folder and load that, Chrome sees a second extension. Remove the old card so you do not get two play buttons on every heading.
