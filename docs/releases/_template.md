## Install

1. Download **`earsup-__VERSION__.zip`** from the assets below.
2. Extract it to a folder you will keep.
3. Open `chrome://extensions`, turn on **Developer mode**, and click **Load unpacked**.
4. Select the extracted folder (the one with `manifest.json`).

Updating? Extract over the same folder, then click the reload arrow on the EarsUp card. Your settings and history stay.

Full guide: [Installation](https://lovestaco.github.io/earsup/installation/)

## Verification

Open the EarsUp settings and go to **About**. The version should read **__VERSION__**.
